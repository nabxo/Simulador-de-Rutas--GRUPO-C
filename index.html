¿Cómo Funciona?

Cálculo de Tiempo: Se suma el tiempo base de cada tramo. Por cada alerta activa, el tiempo se multiplica por (1 + porcentaje/100).

Cálculo de Costo: Se suma el costo de cada tramo más los costos extras de las alertas activas.

Ordenamiento: Por defecto se ordenan por tiempo, pero puedes cambiar a costo o número de transbordos.
